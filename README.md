# TripnAI

Plan with your favorite AI. Travel with TripnAI.

This repository is the Cursor Marketplace plugin. The repo root is the plugin.

MCP server: `https://tripnai.com/api/mcp` (OAuth on tripnai.com).

## Install

In Cursor, add this plugin from the marketplace, or add the MCP URL directly:

```json
{
  "mcpServers": {
    "tripnai": {
      "url": "https://tripnai.com/api/mcp"
    }
  }
}
```

Then enable the tripnai server and sign in on tripnai.com when OAuth opens. Ask the agent to list your trips.

## Publish

See [PUBLISH.md](PUBLISH.md). Submit while signed in as `xk2@me.com`.
