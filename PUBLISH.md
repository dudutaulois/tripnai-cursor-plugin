# Publish to the Cursor Marketplace

1. Sign in to Cursor as `xk2@me.com`.
2. Open https://cursor.com/marketplace/publish
3. Submit this repo: https://github.com/dudutaulois/tripnai-cursor-plugin

The MCP URL stays `https://tripnai.com/api/mcp`. Do not point the listing at the private TripnAI monorepo or at a nested folder.

To refresh this repo from the monorepo copy later, rsync `connectors/cursor/tripnai/` here, keep this README, LICENSE, and PUBLISH.md, then commit and push only this repo.
